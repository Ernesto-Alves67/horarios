# Horários

Aplicação para facilitar a vizualização de horários de aulas gerados a partir do SIGAA).

---
## Como usar:
- [Baixe o apk](https://github.com/Ernesto-Alves67/horarios/releases/download/v1.10.7/app-release.apk)
- Gere seu comprovante de matricula no SIGAA da sua universidade e baixe a pagina html gerada.
  
## Funcionalidades:
- Vizualização das aulas do dia
- Vizualização semanal das aulas matriculadas
